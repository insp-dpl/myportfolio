Overview

A Rails app for wine tasting events where guests vote in real time and admins approve submissions.

Stripe handles payments, and Stripe Identity handles user verification.

What I built

  • Real-time voting with JavaScript
  • Admin approval workflow
  • Stripe payments plus Stripe Identity verification
  • Role-based permissions and single sign-on with multiple OAuth providers
